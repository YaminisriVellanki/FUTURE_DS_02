Customer Retention & Churn Analysis Dashboard

Project Overview
 This project presents an interactive Power BI dashboard developed to analyze customer retention and churn patterns for a subscription-based business. The dashboard helps identify customer behavior trends, retention performance, churn risks, and key business insights to support data-driven decision-making.

Tool Used - Power BI

 Key Features
- Interactive and dynamic dashboard
- KPI cards for business metrics
- Customer churn analysis
- Retention trend visualization
- Customer segment analysis
- Business insights and recommendations

 Objectives
- Analyze customer churn patterns
- Identify retention trends and customer behavior
- Understand factors influencing customer loss
- Provide actionable recommendations to improve retention

 Dashboard Insights
- Identified customer groups with higher churn rates
- Analyzed retention performance across customer segments
- Highlighted important churn-related patterns
- Provided insights to improve customer engagement and retention

Learning Outcomes
 Through this project, I improved my skills in:
- Data Visualization
- Dashboard Design
- KPI Analysis
- Business Analytics
- Insight Generation
- Interactive Reporting

 Conclusion
This project demonstrates the use of Power BI for customer retention and churn analysis through interactive visualizations and business insights. 
The dashboard helps in understanding customer behavior, identifying churn risks, and supporting strategic business decisions.
